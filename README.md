# supra-organism rig

Live SuperCollider interface for the Supra-Organism rehearsals: FlowEdit morph, latent collage,
concatenator, and the set panes: wall of sound, metronomes and LatentFT. Lives at
`supra-organism/rig/` and locates its sibling repos relative to itself, so it runs on either Mac.

Start with `HANDOFF.md`. Runbook for the existing tabs: `../sa-flowedit/STUDIO-RIG.md`.

Tabs 4–6 (WALL OF SOUND, METRONOMES, LATENTFT) are the rehearsal set panes; see HANDOFF.md for the lane mapping and modes.
